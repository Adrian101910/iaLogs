# Changelog

## 0.1.0

- API de ingesta y consulta con autenticación, límites, filtros y migraciones PostgreSQL.
- Explorador React y TypeScript.
- Integración local con Ollama: diagnóstico validado, evidencias e historial.
- Portal PHP/MySQL y paquete para hosting compartido.
- Colectores de archivos y Docker CLI.
- Arranque reproducible, credenciales por instalación, licencia MIT y GitHub Actions.

Primera versión funcional de autohospedaje. No incluye pagos ni aislamiento multiempresa.
